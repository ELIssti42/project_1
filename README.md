Игра "Виселица".

Возможности:
1. Интерфейс с элементами масштабируется.
2. Есть статистика(общий счёт, побед, поражений и рекорда). Приложение сохраняет статистику, даже после закрытия.
3. Есть возможность выбрать категорию.
4. Можно выйти обратна на главное окно, во время раунда с помощью "Меню".

Для игры нужно устоновить:

1. pip install pyqt6
2. python -m venv venv
3. venv\Spcripts\activate

Как играть:
1. В меню выберите категорию.
2. Нажать на "Начать игру"
3. Нажимайте на буквы.
4. если вы выиграете раньше, чем у вас закончатся попытки - вы победили! В ином случаи - вы проиграете... :(
